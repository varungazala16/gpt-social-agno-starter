# Agno Starter - Mock Project

AI agent integration demo using [Agno](https://agno.com) and [CopilotKit](https://copilotkit.ai).

## Quick Start

```bash
cd with-agno
pnpm install
echo "OPENAI_API_KEY=your-key-here" > agent/.env
pnpm dev
```

Visit http://localhost:3000 to see the app.

## What's Included

- Investment analyst AI agent with stock research capabilities
- Next.js frontend with CopilotKit integration
- Python backend with Agno framework

## Requirements

- Node.js 18+
- Python 3.8+
- OpenAI API Key
- pnpm (recommended)

For detailed setup instructions, see [with-agno/README.md](./with-agno/README.md).
